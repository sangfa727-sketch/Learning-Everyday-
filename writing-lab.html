အက္ခရာတစ်လုံးကို ရွေးပြီး လက်ချောင်း သို့မဟုတ် Stylus ဖြင့် ရေးပါ။ Stroke တစ်ကြောင်းချင်းစီ၏ စတင်/ဆုံးမှတ်၊ အစဉ်၊ အချိန်နှင့် မူရင်းလမ်းကြောင်းကို သိမ်းပြီး Animation ပြန်ကြည့်နိုင်သည်။ ချောမွေ့မှုကို အနည်းငယ်သာ အသုံးပြုပြီး သင်ရေးထားသောပုံစံကို အစားမထိုးပါ။

သဘာဝအတိုင်း65%ပိုချောမွေ့
ရွေးထားသောအက္ခရာကို မှတ်တမ်းတွင် ချိတ်ဆက်သိမ်းမည်။ လက်ရှိဗားရှင်းသည် သင်ရေးသောပုံကို ရွေးထားသည့်အက္ခရာနှင့် အလိုအလျောက်တိုက်စစ်ပြီး မှန်/မမှန် အတည်ပြုနိုင်သေးခြင်း မရှိပါ။

မူရင်းလမ်းကြောင်း

ချောမွေ့ပြန်ဖော်ထားသောလမ်းကြောင်း

Stabilized Pen သည် လက်တုန်ခါမှုကို လျှော့ပြီး Curve Pen သည် လမ်းကြောင်းကို ပိုမိုချောမွေ့သော curve ဖြင့် ပြသသည်။ Natural Pressure Pen တွင် pen pressure ရရှိပါက အသုံးပြုပြီး mouse ဖြင့်ရေးလျှင် အမြန်နှုန်းနှင့် အကွေ့အပေါ် မူတည်၍ အထူအပါးကို ခန့်မှန်းပေးသည်။ မူရင်း stroke မှတ်တမ်းကို မပြောင်းလဲပါ။

သိမ်းထားသော အက္ခရာမှတ်တမ်းများ

မှတ်တမ်းများကို ဤစက်၏ browser local storage ထဲတွင်သာ သိမ်းသည်။ Server သို့ အလိုအလျောက် မပို့ပါ။ Browser data ကို ရှင်းလင်းလျှင် local မှတ်တမ်းများ ပျောက်နိုင်သောကြောင့် JSON export ကို backup အဖြစ် သိမ်းနိုင်သည်။
